# Upcoming Features

This document tracks the upcoming features and roadmap for Sanskar's PDF Editor.

## Cross-Platform Expansion
- **Web Version**: Full browser-based PDF editing capabilities utilizing WebAssembly (Wasm) and PDF.js.
- **Android App**: Native Android application offering touch-optimized PDF reading, annotation, and manipulation.
- **Linux Support**: Official `.AppImage` and `.deb` releases with native Wayland/X11 support.

## Advanced PDF Features
- OCR (Optical Character Recognition) for scanned documents
- Digital Signatures and Certificate verification
- Advanced Form filling and extraction
- PDF Redaction tools (permanent removal of sensitive data)
- Batch Processing (watermarking, converting, compression)
- Dark Mode enhancements across all OS themes
- Cloud Sync and Collaboration (Google Drive, OneDrive integration)
- Automated translation of text within PDFs

*Stay tuned for these exciting additions!*
