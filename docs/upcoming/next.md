# Upcoming Features (Next Steps)

This document outlines the next set of features planned for Sanskar's PDF Editor.

## Planned Platforms
- **Linux Native Build**: We will compile the Tauri app natively for Ubuntu/Debian (`.deb`) and Arch (`.AppImage`), bringing the ultimate PDF engine to Linux users.
- **macOS Native Build**: Support for Apple Silicon (`.dmg`) using Tauri.

## Planned Features
- **AI OCR Integration**: Extract text directly from scanned images using Tesseract.js in the Interactive Studio.
- **Cloud Sync**: Integrate Firebase/Supabase for saving and syncing PDFs seamlessly.
