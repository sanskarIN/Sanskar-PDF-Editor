# Sanskar PDF Editor - Enterprise Edition (v0.0.1.6)

Welcome to **Sanskar's PDF Editor**! This project is an ultimate, enterprise-grade, offline-first PDF Editor featuring 70+ advanced tools. Built with React, Tauri v2, and Rust for lightning-fast, secure performance across Windows, Android, and Web.

## The Ultimate Hybrid Architecture
A blazingly fast PDF Editor built with React, Vite, Node.js, and Tauri v2.

- **Offline-First**: All processing is done locally on your machine.
- **70+ Tools**: Merge, Split, Convert, Encrypt, Sign, Redact, and more.
- **Military-Grade Security**: AES-256-GCM encryption for your PDFs.
- **Cross-Platform**: Available as Windows (.exe, .msi), Android (.apk), and a standalone Web Version (`Web-Version.html`).
