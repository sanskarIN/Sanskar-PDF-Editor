# Sanskar PDF Editor - Enterprise Edition

Welcome to **Sanskar's PDF Editor**! This project is completely Open Source. 
Users who have the source code can view the `docs/users_suggest/` folder to suggest next and upcoming features.

## The Ultimate Hybrid Architecture
A blazingly fast PDF Editor built with React, Vite, Node.js, and Tauri v2.

### Getting Started
Please see the `docs/run/` folder for instructions on how to run this project in different environments (Desktop, Web, Frontend-only, Backend-only).

### Community
Feel free to open issues and pull requests to add new tools to the editor!
